⚠️ Live Server Cannot Run Full-Stack React Apps

You opened this project using VS Code's "Go Live" extension. "Go Live" is only designed for basic, static HTML pages and cannot compile React (JSX) or run Node.js/Express backend APIs.

How to start the app properly:

  1. Easiest: Double-click the run-app.bat file inside this folder.
  2. Or from VS Code Terminal: Press Ctrl + ` and run: 
    cd frontend && npm run dev

Once started, your application runs live at:

Open App (http://localhost:5173)
